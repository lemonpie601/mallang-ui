# Mallang (말랑) 0.1.0

Marinara Engine **v2.5.1**을 말랑한 파스텔 톤으로 바꾸는 개인 확장입니다.

## 하는 일
- 크림, 세이지, 라벤더 팔레트와 잉크색 굵은 외곽선(1.5px + 아래쪽 3px 그림자)을 앱 전체 색 토큰에 적용합니다. 라이트와 다크 모두 지원합니다.
- 상단 바, 채팅 입력창, 플로팅 창, 모달, 팝오버를 둥근 알약 모양으로 바꾸고, 누르면 말랑하게 눌리는 효과를 줍니다.
- 화면 크기에 맞춘 촘촘한 레이아웃: 노트북(1280~1599px)에서 상단 바 40px, 채팅 사이드바 232px. 높이 760px 이하에서는 입력창과 서랍 행을 더 줄이고, 대화 설정 창의 안내 문단을 숨깁니다.
- 휴대폰(767px 이하) 홈, 대화 목록 등 허브 화면에만 하단 탭(홈 · 대화 · 서재 · 작업실)을 띄웁니다. 탭은 Marinara 상단 바의 기존 버튼을 대신 눌러 줄 뿐입니다. 채팅 안과 키보드가 열려 있을 때는 숨깁니다.
- 동작 효과를 끌 수 있습니다. 브라우저의 "동작 줄이기" 설정도 따릅니다. 개발자 도구 콘솔에서 `__mallang.setMotion("off")`로 끄고 `"on"`으로 켭니다.
- MARINARA98이 함께 켜져 있으면 경고 알림을 띄웁니다.

## 하지 않는 일
- Marinara의 데이터(채팅, 캐릭터, 설정)를 읽거나 쓰지 않습니다. 네트워크 요청도 보내지 않습니다.
- 메시지 본문, 캐릭터 카드 CSS(`data-card-css`), 게임 모드(`data-chat-mode="game"`) 내부 화면은 건드리지 않습니다(색 토큰만 바뀝니다).
- 외부 폰트를 받지 않습니다. Marinara의 보안 정책(CSP)이 외부 스타일시트와 폰트를 막기 때문에 시스템 글꼴(Apple SD Gothic Neo, 맑은 고딕)을 씁니다.
- 0.1.0에는 홈 피드 위젯 스타일, 태블릿 아이콘 레일, 하단 탭의 ＋ 버튼, 서랍 5탭 재분류가 없습니다.

## 설치
1. Marinara 서버의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 서버를 다시 시작합니다.
2. **설정 > 고급 > Danger Zone**에서 **Allow third-party extension imports**를 켭니다.
3. 이 저장소를 GitHub에서 설치하거나, 폴더(또는 ZIP)를 **설정 > 애드온 > External Extensions**에서 가져옵니다.
4. 가져온 확장은 꺼진 상태입니다. `manifest.json`, `extension.js`, `extension.css`를 확인한 뒤 **Review and Run**에서 표시된 해시를 승인합니다.

## full_page_access 권한이 필요한 이유
일반 확장은 샌드박스 iframe 안에서만 돌아서 Marinara 화면을 바꿀 수 없습니다. 테마를 입히려면 페이지 전체(DOM과 CSS)에 접근해야 하므로 `full_page_access`가 필요합니다. 이 권한은 샌드박스가 없는 코드 실행 권한이라, 코드를 직접 읽어 보고 신뢰할 때만 승인하세요. 코드는 `extension.js` 하나(약 300줄)이고 빌드 과정이 없습니다.

## 끄는 방법
**설정 > 애드온 > External Extensions**에서 Mallang을 **Disable** 하면 `data-mallang*` 속성, 하단 탭, 알림, 리스너가 모두 정리되고 원래 화면으로 돌아갑니다. 테마를 바꾸는 도중에 껐다면 새로고침하세요. 확장을 삭제하면 완전히 제거됩니다.
