# Mallang (말랑) 0.3.0

Marinara Engine **v2.5.1**을 말랑한 파스텔 카드 화면으로 바꾸고, 홈을 작은 모니터에서도 한 화면에 들어오게 다시 배치하는 개인 확장입니다.

## 하는 일
- **색과 모양**: 크림 바탕에 핑크 · 피치 · 라벤더 · 민트 · 버터 색 카드, 진한 1.5px 외곽선과 아래로 살짝 떨어지는 그림자. 버튼은 올리면 살짝 떠오르고 누르면 말랑하게 눌립니다. 라이트와 다크(자두색) 모두 지원합니다.
- **배경**: 앱 뒤에 흐린 피치 · 민트 · 라벤더 얼룩과 점선 낙서 한 줄을 깝니다.
- **채팅 목록 · 오른쪽 패널**: 화면 가장자리에서 떨어진 둥근 카드로 띄우고, 머리 부분을 민트(채팅 목록) · 라벤더(오른쪽 패널) 띠로 칠합니다.
- **모드 탭**: `CONVO(대화)` · `RP(롤플)` · `GM(게임)`을 **콘보 · 롤플 · GM**으로 줄이고, 고른 탭은 검은 알약으로 표시합니다.
- **홈 다시 배치**: 로고와 액자 틀을 빼고, 한 화면을 꽉 채우는 대시보드로 바꿉니다.
  - 홈 위젯을 꺼 두고 API 크레딧만 쓰는 경우: 왼쪽 좁은 칸에 인사말 · 이번 주 날짜 띠 · 대화/롤플레이/게임 카드, 오른쪽 넓은 칸 전체에 **API 크레딧**. 크레딧은 화면 폭에 맞춰 1~4열로 늘어나고, 칸 안에서만 스크롤되어 위아래가 잘리지 않습니다.
  - 홈 위젯을 켜 두면: 위에 인사말과 모드 카드, 아래에 최근 채팅(큰 칸), 나머지 위젯은 작은 타일(제목 + 바로가기 알약)로 줄이고, API 크레딧은 오른쪽 칸에 둡니다.
  - 창이 좁으면(홈 영역 760px 이하) 한 줄로 쌓고 평소처럼 스크롤합니다. 높이 560px 이하에서도 스크롤로 돌아갑니다.
- **채팅**: 채팅 영역을 둥근 카드로 감싸고, `*행동*`은 민트 강조, `"대사"`는 외곽선 말풍선으로 보입니다(대사 색을 직접 지정한 경우, 카드 CSS, 게임 모드는 그대로).
- **작은 화면 촘촘하게**: 768~1279px에서 채팅 목록 276px, 1280~1599px에서 272px, 상단 바 40px. 높이 760px 이하에서는 입력창과 서랍 행을 줄이고, 대화 설정 창의 안내 문단을 숨깁니다.
- **휴대폰**(767px 이하): 홈 · 대화 목록 같은 허브 화면에 노란 알약 하단 탭(홈 · 대화 · 서재 · 작업실)을 띄웁니다. 탭은 상단 바의 기존 버튼을 대신 눌러 줄 뿐이고, 채팅 안과 키보드가 열려 있을 때는 숨깁니다.
- 동작 효과를 끌 수 있습니다. 브라우저의 "동작 줄이기" 설정도 따릅니다. 개발자 도구 콘솔에서 `__mallang.setMotion("off")`로 끄고 `"on"`으로 켭니다.
- MARINARA98이 함께 켜져 있으면 경고 알림을 띄웁니다.

## 하지 않는 일
- Marinara의 데이터(채팅, 캐릭터, 설정)를 읽거나 쓰지 않습니다. 네트워크 요청도 보내지 않습니다.
- Marinara 본체 파일은 건드리지 않습니다. 홈 배치는 모두 CSS로 바꾸며, 엔진이 그린 위젯과 버튼을 그대로 씁니다.
- 캐릭터 카드 CSS(`data-card-css`), 게임 모드(`data-chat-mode="game"`) 내부 화면은 건드리지 않습니다(색 토큰만 바뀝니다).
- 외부 폰트나 이미지를 받지 않습니다. Marinara의 보안 정책(CSP)이 외부 스타일시트와 폰트를 막기 때문에 시스템 글꼴을 씁니다.

## 설치
1. Marinara 서버의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 서버를 다시 시작합니다.
2. **설정 > 고급 > Danger Zone**에서 **Allow third-party extension imports**를 켭니다.
3. 이 저장소를 GitHub에서 설치하거나, 폴더(또는 `mallang.personal-extension.zip`)를 **설정 > 애드온 > External Extensions**에서 가져옵니다. 예전 버전을 쓰고 있었다면 같은 곳에서 새 버전으로 다시 가져옵니다.
4. 가져온 확장은 꺼진 상태입니다. `manifest.json`, `extension.js`, `extension.css`를 확인한 뒤 **Review and Run**에서 표시된 해시를 승인합니다.

## full_page_access 권한이 필요한 이유
일반 확장은 샌드박스 iframe 안에서만 돌아서 Marinara 화면을 바꿀 수 없습니다. 테마를 입히고 홈을 다시 배치하려면 페이지 전체(DOM과 CSS)에 접근해야 하므로 `full_page_access`가 필요합니다. 이 권한은 샌드박스가 없는 코드 실행 권한이라, 코드를 직접 읽어 보고 신뢰할 때만 승인하세요. 코드는 `extension.js` 하나(약 340줄)이고 빌드 과정이 없습니다.

## 끄는 방법
**설정 > 애드온 > External Extensions**에서 Mallang을 **Disable** 하면 `data-mallang*` 속성, 배경, 홈 인사말 · 날짜 띠, 하단 탭, 알림, 리스너가 모두 정리되고 원래 화면으로 돌아갑니다. 테마를 바꾸는 도중에 껐다면 새로고침하세요. 확장을 삭제하면 완전히 제거됩니다.
